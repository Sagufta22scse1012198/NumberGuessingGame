# NumberGuessingGame
A Java-based Number Guessing Game that generates a random number between 1 and 100. The user receives hints (Too High/Too Low) until the correct number is guessed. Developed as Task 1 for the CODSOFT Java Programming Internship.
# Number Guessing Game

## Description
A Java console application where the user tries to guess a randomly generated number between 1 and 100.

## Features
- Random number generation
- User input using Scanner
- Too High / Too Low hints
- Attempt counter
- Displays success message when guessed correctly

## Technologies Used
- Java
- IntelliJ IDEA
